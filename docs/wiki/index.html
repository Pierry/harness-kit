harness-kit Wiki

harness-kit is a set of Claude Code agents that take an idea to a merged PR through one gated pipeline, plus a system-architect agent that writes System Design Docs. The repo holds the terse agent-facing files. This wiki holds the theory and the study material. Start with Harness Engineering.

Autonomy and subagents

You approve direction at two gates and everything between runs on its own. An intake stage harvests context first, and an orchestrator dispatches single-purpose subagents.

Page Covers
Autonomy intake, resolve-mark-proceed, /pipeline:run
Orchestration and Subagents orchestrator and leaves, writer and critic split, model tiering

The canonical shape is .claude/shared/pipeline-pattern.md. Haiku tiering and per-org repos.md are still (planned).

System design

The system-architect agent runs one playbook per episode of the System Design series. A design doc is an optional front stage before the main pipeline: it feeds a sharper PRP and plan.

Page Design problem
System Design Method the 13-stage method, three pillars, back-of-envelope numbers
URL Shortener (#1) read-heavy lookup, short-code generation, cache, abuse
Rate Limiter (#2) token bucket, fail-open, multi-region budgets
Search Engine (#3) crawler, indexing, ranking, query serving

Next candidates are API gateway, distributed queue, news feed, distributed cache, and notification system.
